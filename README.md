# 秋招记录小助手

一个跑在自己电脑上的秋招投递台账。中文界面，数据只存本地，不依赖任何云服务；AI 是可选项，用你自己的接口。

主要功能：

- 记录每一次投递的公司、岗位、志愿（第 1/2/3 志愿或人才计划）、方向、地点、投递日期、简历筛选结果和当前步骤。
- 同一家公司归为一条展示，下面分列各志愿，不再一条投递一行。
- 状态简化为六档，每档一种颜色：**简历筛选中 / 笔试 / 面试 / Offer / 已结束 / 已撤回**。列表可按状态筛选。
- 「笔试与面试」是月/周日历，可记录笔试、多轮面试和下一步安排。
- 从招聘网站一键识别：登录好官网，把“我的投递/应聘记录”的网址填进来，自动读出多个岗位和状态。
- 每条记录都能单独核对；单条核对照样按整页处理，同一网址下的多个岗位会一起更新。
- 一键核对全部：同一个网址只打开一次页面，页面里的岗位一起匹配；后台标签运行，不抢占前台。
- AI 优先：启用 AI 后，由模型直接看当前页面文字和整页截图判断状态，本地不再用关键词规则改写结果。
- 支持 CSV 导入导出、按日期/公司/状态排序、本地历史版本快照。
- 可自定义 AI 接入：OpenAI 兼容接口或 Claude `/messages` 接口，地址、密钥、模型都由你填。

## 状态与颜色

| 状态 | 颜色 |
| --- | --- |
| 简历筛选中 | 蓝 |

## 需要准备

- [Node.js](https://nodejs.org/) 22 或以上（Windows / macOS / Linux 都行）。
- Edge 浏览器（用于加载采集扩展）。
- 可选：一个 AI 接口。不配置也能用，只是识别不确定时不会调用 AI。

## 快速开始

1. 下载或克隆本项目。

2. 启动本地服务：
   - **macOS**：双击 `start.command`；
   - **Windows**：在本项目文件夹里打开终端（PowerShell），运行 `node launch.mjs`；
   - **任意系统**：命令行运行：

     ```sh
     node launch.mjs
     ```

3. 浏览器打开 <http://127.0.0.1:4319>。

4. 加载采集扩展（只需一次）：
   - Edge 地址栏输入 `edge://extensions`，打开「开发人员模式」；
   - 点「加载解压缩的扩展」，选择本项目的 `extension` 文件夹；
   - 回到台账页，点左下角「连接与运行日志」→「连接浏览器」。
   - 之后每次更新扩展代码，都要在这里点一次「重新加载」。

5. 记录投递，两种方式：
   - 手动：点「手动记录」逐条填写；
   - 自动：在官网登录后打开「我的投递 / 应聘记录」页面，复制网址，点「从投递页识别」，粘贴网址 → 解析 → 核对结果 → 保存。

## 配置 AI（可选）

进入「连接与运行日志」，填写：

- **API 地址**：你的接口地址，例如 `https://你的网关/v1`；
- **接口格式**：自动 / OpenAI 兼容 `/chat/completions` / Claude `/messages`；
- **API Key**：只保存在本机 `data/tracker/` 目录，接口不会回显；
- **模型名称**：任意你接口支持的模型，可点上方快捷按钮。

填好后点「测试连接」确认。密钥不会写进代码，也不会出现在网页里。

## 数据与隐私

- 所有记录和密钥都保存在本机 `data/tracker/`，并已被 `.gitignore` 忽略。
- 服务只监听 `127.0.0.1`，局域网其他设备访问不到。
- 网页内容只在你点击核对/识别时才读取；采集时页面上的邮箱、手机号、证件号会先替换成占位符再交给 AI。
- HTTP 页面没有传输加密，介意的话请在 HTTPS 站点使用。
- 每次保存都会生成新的历史快照，不覆盖旧数据，可从 `data/tracker/revision-*.json` 找回。

## 常见问题

- **端口被占用**：`PORT=4319 node launch.mjs` 换一个端口。
- **提示“扩展版本过旧”**：先在 `edge://extensions` 对本项目的 `extension` 点一次「重新加载」。服务端只接受当前版本的扩展。
- **改了代码但没生效**：重启本地服务；浏览器里再刷新一次台账页面。界面左下角显示当前界面版本。
- **识别不到岗位**：先确认浏览器里已登录，且页面是「我的投递 / 应聘记录」，而不是招聘职位列表。核对后可在「连接与运行日志」里查看每条读到了多少字、是否疑似登录页。
- **AI 报错**：先在设置里点「测试连接」；确认密钥、地址、模型和接口格式匹配。使用带思考的模型时，请保留足够输出额度。
- **某条一直“等待截图”**：页面加载慢或该站点需要重新登录。任务超时会自动跳过，不会卡住整轮。
- **想清空数据**：直接删除 `data/tracker/` 目录即可（会丢失历史，请先导出 CSV）。

## 目录说明

```
launch.mjs        启动脚本（校验端口并托管 server.mjs）
start.command     macOS 双击启动
server.mjs        本地服务与 API
app.js / index.html / style.css   网页界面
model.mjs         记录与状态规则
ai.mjs / models.mjs   AI 接入与模型预设
calendar.mjs / calendar-ui.mjs     日历与日程
bridge.mjs        网页与扩展的握手
extension/        Edge 采集扩展（整页文字与分段截图，交给 AI 判断）
vendor/           本地化的第三方库（FullCalendar / Lucide / Papa Parse）
test-tracker.mjs  离线测试（node --test）
docs/screenshots/ 界面截图
```
